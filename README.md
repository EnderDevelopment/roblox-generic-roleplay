# Roblox Roleplay Game with Money Trees

This project includes scripts for a Roblox roleplay game featuring money trees with ESP (Extra Sensory Perception) and automatic teleportation to the leader, including money tree teleportation. The scripts handle server-side logic for money trees, client-side logic for ESP creation and input handling, and teleportation to the leader and money trees.

## Install

1. Download the project files.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Navigate to the `ServerScriptService` folder in the Explorer.
5. Create a new Script named `MoneyTreeServerScript` and paste the contents of `MoneyTreeServerScript.server.lua`.
6. Navigate to the `StarterPlayerScripts` folder in the Explorer.
7. Create a new LocalScript named `MoneyTreeClientScript` and paste the contents of `MoneyTreeClientScript.client.lua`.
8. Create a new LocalScript named `TeleportToLeaderScript` and paste the contents of `TeleportToLeaderScript.client.lua`.
9. Create a new LocalScript named `TeleportToMoneyTreeScript` and paste the contents of `TeleportToMoneyTreeScript.client.lua`.

## Use

1. Start the Roblox game.
2. Players can press the 'E' key to register a money tree at their current position.
3. Players can press the 'T' key to teleport to the leader.
4. Players can press the 'M' key to teleport to a money tree.
